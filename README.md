# Maison Elyra Perfume E-commerce

Modern luxury perfume e-commerce front-end built with Vite, React, TypeScript, TailwindCSS, GSAP, React Router, and lucide-react.

## Features

- Luxury desktop mega navigation and mobile drawer
- Home, shop, product detail, cart, checkout, account, journal, about, and help pages
- Mock perfume catalog with IDR pricing for Indonesia
- Cart and wishlist state persisted in `localStorage`
- GSAP page, drawer, menu, product, and scroll reveal motion
- Netlify-ready SPA routing via `netlify.toml`

## Local Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```

## Netlify

- Build command: `npm run build`
- Publish directory: `dist`

The included `netlify.toml` redirects all routes to `index.html` so React Router pages work after deploy.
